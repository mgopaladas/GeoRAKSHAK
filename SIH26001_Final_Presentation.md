# SIH26001 - GeoRakshak
### AI-Powered Intelligence Platform for Real-Time Landslide Prediction & Warning
**Ministry of Development of North Eastern Region (MDoNER)**

---

## 1. Problem Statement
Landslides in the North Eastern Region (NER) and high-elevation topographies inflict catastrophic damage to localized communities. Current monitoring approaches react **too late**, relying heavily on manual observation or post-event satellite imagery rather than preempting ground saturation via dynamic continuous metrics.

## 2. The GeoRakshak Solution
GeoRakshak bridges physical IoT sensors, highly localized terrain mapping, and 48-Hour predictive weather pipelines into a **stateful real-time Machine Learning Intelligence gateway**.

### Key Innovations:
1. **Edge ML-Inference:** Instead of a generic API, physical parameters (Tilt Magnitude + Soil Moisture) merge with 48-HR Cloud-Rainfall Forecasts into an optimized **Gradient Boosted algorithm**, classifying structural weaknesses inherently before displacement occurs.
2. **Authoritative GIS Tracking:** Mapping utilizes official Survey of India boundary integrations alongside 120-ISRO certified historic landslide reference clusters to generate a fully localized risk plane.
3. **Hardware Agnosticism:** Complete backend readiness to scale standard C++ ESP32/MPU6050 physical tilt-meters instantaneously out-of-the-box.
4. **Resiliency:** The Government Web Portal degrades cleanly, caching WebSocket metrics efficiently (50-chunk memory limits) ensuring Next.js doesn't crash during intense anomaly barrages.

---

## 3. Technology Stack & Ecosystem
- **Cloud Gateway:** FastAPI, Python, SQLAlchemy, PostgreSQL + PostGIS (Geo-spatial query extensions).
- **Physical Integration (IoT):** C++ (ESP32 Firmware), Micro-controllers, MPU6050 Accelerometers.
- **Frontend / Command Center:** Next.js (TypeScript), Leaflet / React-Leaflet GIS.
- **Machine Learning Core:** Scikit-Learn (Random Forests for static topological susceptibility + Gradient Boosted Trees for real-time Dynamic trigger anomalies).
- **Field Reporting:** React Native (Expo) field-app with offline storage caching frameworks.

---

## 4. Operational Scalability
Designed natively as a modular containerized micro-service pipeline, GeoRakshak is inherently designed to jump beyond NER into the Himalayas and Western Ghats. Incorporating Sentinel-1 SAR (Synthetic Aperture Radar) processing into the `data_catalogue` architecture is formally structured for Version 2.0.
