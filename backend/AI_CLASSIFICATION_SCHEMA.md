# GeoRakshak — Master Classification Label Set

This document defines the strict, multi-dimensional classification schema that the GeoRakshak AI fusion engine must follow for the SIH26001 demonstration. 
Crucially, **GeoRakshak must never infer current landslide risk from a single label or hotspot priority**. Current risk must be evidence-derived from terrain susceptibility, dynamic triggers, ground movement, satellite observations, and exposure.

## A. SUSCEPTIBILITY CLASSES (Long-term terrain propensity)
`SUS-00` = VERY_LOW_SUSCEPTIBILITY
`SUS-01` = LOW_SUSCEPTIBILITY
`SUS-02` = MODERATE_SUSCEPTIBILITY
`SUS-03` = HIGH_SUSCEPTIBILITY
`SUS-04` = VERY_HIGH_SUSCEPTIBILITY

## B. RAINFALL / ENVIRONMENTAL TRIGGER CLASSES (Current forcing)
`TRG-00` = NO_TRIGGER
`TRG-01` = WEAK_TRIGGER
`TRG-02` = MODERATE_TRIGGER
`TRG-03` = STRONG_TRIGGER
`TRG-04` = EXTREME_TRIGGER

## C. GROUND MOVEMENT CLASSES
`MOV-00` = NO_SIGNIFICANT_MOVEMENT
`MOV-01` = LOW_MOVEMENT
`MOV-02` = MODERATE_MOVEMENT
`MOV-03` = HIGH_MOVEMENT
`MOV-04` = ACCELERATING_MOVEMENT

## D. SATELLITE / REMOTE-SENSING CHANGE CLASSES
`SAT-00` = NO_SIGNIFICANT_CHANGE
`SAT-01` = MINOR_CHANGE
`SAT-02` = POTENTIAL_DISTURBANCE
`SAT-03` = SIGNIFICANT_DISTURBANCE
`SAT-04` = MAJOR_DISTURBANCE

## E. HISTORICAL LANDSLIDE EVIDENCE CLASSES
`HIS-00` = NO_KNOWN_INVENTORY_EVENT (Does not mean NO_LANDSLIDE_EVER)
`HIS-01` = HISTORICAL_EVENT_RECORDED
`HIS-02` = MULTIPLE_HISTORICAL_EVENTS
`HIS-03` = RECURRENT_LANDSLIDE_ZONE
`HIS-04` = HISTORICALLY_CRITICAL_CORRIDOR

## F. CURRENT LANDSLIDE RISK CLASSES (Main AI Output)
`RISK-00` = STABLE
`RISK-01` = LOW_RISK
`RISK-02` = MODERATE_RISK
`RISK-03` = HIGH_RISK (Significant hazard possibility; priority monitoring/action)
`RISK-04` = CRITICAL_RISK (Multiple strong signals; immediate authority review)

## L. FIELD REPORT VALIDATION STATUS

The 120 representative hotspot seed points are reference/monitoring locations and must initially have `status_class = REFERENCE` and `confidence_class = INSUFFICIENT_DATA` (or AUTH-01) until authoritative evidence is ingested.
